## The Group update
* A `G` button as been added to the top left. When pressed it opens the `Group Edit Mode` screen.
* In the `Group Edit Mode` screen, you can apply groups to nearby armor stands by selecting them in the list and pressing the + or - to add / remove from the group
* Pressing the group button will cycle through 8 predefined groups.
* You can also create custom groups by typing a name in the text box.
* You can then edit the entire group of armor stands at the same time by pressing the `Pose Group` button near the bottom.


### Use with caution
Please be sure to report any bugs you find with the new group system. It was a large change and there may be some weirdness.
